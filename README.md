# Market Pulse

A personal market dashboard: live quotes (indices, Treasury yields, VIX, dollar, crude, gold, crypto), a U.S. economic calendar, market news, and a release playbook explaining how hot or cool data prints tend to move markets.

Single static page (`index.html`) served by GitHub Pages. Live data comes from free TradingView widgets; stock/index data may be delayed under exchange rules.

To change the tracked symbols, edit the `TAPE` and `OVERVIEW_TABS` lists near the top of the script in `index.html`.
